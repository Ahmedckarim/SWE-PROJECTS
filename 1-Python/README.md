# 🧠 Project Rules

For every major project, I will follow this process:

### 1. Build

Create the first working version without focusing on perfection.

### 2. Refactor

Improve:

* Code structure
* Function design
* Naming
* Reusability
* Readability

### 3. Test

Try to break the application using:

* Invalid input
* Empty input
* Wrong data types
* Edge cases
* Unexpected situations

### 4. Improve

Add new features and improve the architecture.

### 5. Document

Every major project should contain:

```text
README.md
Source Code
Requirements
Usage Instructions
Features
```

### 6. Git

Use Git throughout the project.

```bash
git add .
git commit -m "..."
git push
```
